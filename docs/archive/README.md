# Archiv dokumentacie

Toto je archiv starsich, historickych alebo uz menej pouzivanych dokumentov.

Archiv sluzi na zachovanie kontextu bez prehlcovania root adresara.

## Struktura

- `setup/` - stare setup a env dokumenty
- `notes/` - stare fix/summary poznamky
- `context/` - interny projektovy kontext
